{{- /* Overrides Hugo's built-in alias template. The default alias stub is a bare redirect: title, canonical, charset, refresh. Social scrapers do not follow the meta refresh, so a link shared at an old URL previewed as nothing at all — worse than the plain text box, because there is no title or description to fall back on either. Post slugs were renamed once, so several published URLs are aliases. This gives those stubs the same Open Graph and Twitter tags as their target, meaning an old link still previews correctly while continuing to redirect real browsers. Context here is not a Page: it provides .Permalink (the target URL) and .Page (the target page), so everything below reads from .Page. noindex is deliberate — the canonical URL should be the one that ranks. */ -}} {{- $p := .Page -}} {{ $p.Title | default .Permalink }} {{- $desc := "" -}} {{- with $p.Description }}{{ $desc = . }}{{ else }}{{ with $p.Summary }}{{ $desc = (. | plainify | truncate 200) }}{{ else }}{{ $desc = site.Params.description }}{{ end }}{{ end -}} {{- $og := partial "og-image.html" $p -}}
