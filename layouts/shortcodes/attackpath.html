{{- /* Renders a Compromise Canvas on-host attack path as an ordered chain, straight from the exported canvas JSON — so the post shows the same path the tool does, and can't drift out of date the way a screenshot would. {{< attackpath key="pyarmor_pyinstaller_loader" download="https://..." >}} Reads site.Data.attackpaths. and walks diagram.nodes to find the host node carrying data.actions (the on-host steps added in SagaLabs/CompromiseCanvas#21). Steps are rendered in array order, because array order *is* the path — timestamps can be missing, identical or skewed, and the analyst's reconstruction is what matters. Each action carries: type (tactic), technique (what happened), details (the command line), timestamp, mitreAttackId, mitreAttackName. Params: key (required) data file under data/attackpaths/, underscores not hyphens download optional URL to the canvas JSON, rendered as a footer link */ -}} {{- $key := .Get "key" -}} {{- $c := index site.Data.attackpaths $key -}} {{- if not $c -}} {{- errorf "attackpath: no canvas data for key %q (looked in data/attackpaths/%s.json)" $key $key -}} {{- end -}} {{- $steps := slice -}} {{- $host := "" -}} {{- $ip := "" -}} {{- range $c.diagram.nodes -}} {{- with .data -}} {{- if and (eq (len $steps) 0) .actions (gt (len .actions) 0) -}} {{- $steps = .actions -}} {{- $host = .label | default .hostname | default "host" -}} {{- $ip = .ipAddress | default "" -}} {{- end -}} {{- end -}} {{- end -}} {{- if eq (len $steps) 0 -}} {{- errorf "attackpath: canvas %q has no node carrying data.actions" $key -}} {{- end -}}
